## Why this book exists

The Knowledge Vault platform recently gained a **mobile app** (an Android application).
Most people in the organization have never seen it, don't know where it lives in the
codebase, and don't know how to build or install it.

This book is the **knowledge transfer (KT)**. Its job is to take a reader from *"I have
no idea what this is"* to *"I understand it, I can build it, and I could explain it to
someone else."* That last part matters — this material is also the **script source for a
set of short training videos**.

## Who this book is for

You do **not** need to be a mobile developer. The book is layered:

| If you are… | You will care about… |
|-------------|----------------------|
| A manager / trainer | Chapters 1–3 and 5 (concepts + how to install) |
| QA / support | Chapters 1–4 and 11 (how it works + troubleshooting) |
| A web developer new to mobile | The whole book, especially 2–4 and 6–8 |
| DevOps / release engineer | Chapters 5, 8, 9 (CI, signing, distribution) |

## What you need before you start

Nothing at all for the concept chapters (1–3). For the hands-on chapters:

- **To download a ready-made APK (Chapter 5):** a GitHub account with access to the
  repository, and an Android phone. **No coding tools required.**
- **To build locally (Chapter 6):** a computer with the Flutter SDK and Android SDK
  installed. Chapter 6 walks you through installing these.

## How to read it

- **As a course:** go front to back. Each chapter assumes the ones before it.
- **As a reference:** use the [Index](./index.md) table or the
  [Quick Reference appendix](./appendix-b-quick-reference.md) to jump straight to a topic.

## The callouts you'll see

Throughout the book, watch for these:

> **💡 Concept** — a plain-English explanation of an idea.

> **⚙️ Hands-on** — a step you can actually perform.

> **⚠️ Watch out** — a common mistake or gotcha.

> **🎬 Video script hint** — a suggestion for turning the section into a short video.

Each chapter closes with:

- **Key takeaways** — the 3–5 things to remember.
- **Check yourself** — quick questions to confirm you understood.

## A note on accuracy

Every file path, command, and code snippet in this book is taken directly from the
repository as it exists today. If the app changes, the person who changes it should
update the matching chapter so this KT never goes stale.
